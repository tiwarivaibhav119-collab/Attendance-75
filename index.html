Use Attend75 on Your Phone
1. Android (Google Chrome) Open the app link in Chrome, then tap Install App below (or ⋮ Menu → Install app). Long-press the home-screen icon for quick Present / Absent shortcuts.
2. iPhone / iPad (Safari) Open the web link in Safari, tap the Share (↑) button, and select Add to Home Screen.
3. Compact Widget + Teacher Pace Tap ⊞ Widget in the top bar for a compact card with quick logging and live Teacher Pace status. Your data lives only on this device — use Export Backup now and then.
